# Prompt Midjourney v8.2: asset del nuovo look

**Il tuo compito:** incollare ogni prompt in Midjourney, scegliere la variante migliore delle quattro, fare l'upscale e scaricarla nella cartella `da-importare/` del progetto. Il nome del file non importa: le immagini le riconosco io, le rinomino, le converto e le collego al sito.

Spunta la casella quando hai finito. Totale: **33 immagini**.

## Regole per tutte le immagini

- Niente rinomine, ritagli o ritocchi: basta scaricare l'upscale.
- Scarta una variante se contiene scritte, loghi o cornici, o se un volto ricorda un personaggio esistente. Rigenera senza cambiare il prompt.
- **Coerenza:** quando un'immagine di un gruppo ti convince, copia il suo link e aggiungi `--sref <link>` a tutti gli altri prompt **dello stesso gruppo**. I gruppi sono segnati con 🔗.
- Se Midjourney ti segnala un parametro non valido, toglilo e lascia il resto com'è.
