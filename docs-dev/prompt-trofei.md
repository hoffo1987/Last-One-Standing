# Immagini dei trofei — prompt per Midjourney v8.2

Un'immagine inedita per ognuno dei 40 trofei, nello stesso stile della coppa già importata (assets/fx/trofeo-coppa.webp):
emblema piatto, contorni neri spessi e spigolosi, un solo riempimento bianco, fondo verde pieno (si toglie in automatico).

**Come importarle**
1. Genera ogni prompt e salva l'immagine scelta come `trofeo-<id>.png` (l'id è nella prima colonna), tutte nella stessa cartella.
2. `python -I tools/import-trofei.py <cartella>` → crea `assets/fx/trofeo-<id>.webp`.
3. Il sito le usa da solo: ogni trofeo mostra la sua; finché manca, mostra la coppa.

`bold flat vector emblem, thick angular black outlines, solid white fills only, Persona 5 menu icon style, sharp diagonal cuts, centered, plain solid green background for keying, no text, no letters, no numbers, no shadow --ar 1:1 --v 8.2`
